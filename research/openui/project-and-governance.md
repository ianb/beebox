# OpenUI (thesysdev/openui): project, licensing, governance, adoption, reception

Date: 2026-10-08. Public sources only. Companion to the hands-on code notes in this directory.

## Summary

1. OpenUI is a single-vendor open-source project of Thesys Inc. (San Francisco, $4M seed, Nov 2024). No foundation, standards body, charter, CLA, or trademark policy exists. "Open standard" is a marketing label; the only spec is a docs page inside the implementation repo.
2. All 17 npm packages are MIT. The repo LICENSE says "Copyright (c) 2011-2024 Thesys Inc." (stale). `@openuidev/react-email` has no `license` field in `package.json`.
3. The GitHub repo is the renamed Crayon repo (created 2024-12-02; "Migrate to openui" commit 2026-03-03; first npm publish 2026-03-09; Show HN and Product Hunt 2026-03-11). The star count (10,234) includes pre-rename Crayon stars; I could not separate them.
4. OpenUI replaces Thesys's proprietary C1 JSON format and `@thesysai/genui-sdk` (proprietary, no-redistribution license). C1 docs moved to `/legacy`; "OpenUI is the actively developed successor to C1."
5. The paid product is OpenUI Cloud / Gateway / Autofix / Observability at `api.thesys.dev` ($0, $49, $499/mo, custom). The open packages work without it; the docs and CLI steer toward it.
6. Maturity: seven months old as "OpenUI"; all packages 0.x; 41 GitHub releases; weekly releases via changesets; one minor bump (react-ui 0.17.0, 2026-10-05) swapped Recharts for D3 with renamed and dropped props.
7. Contributors: 13 Thesys staff plus two bots account for about 900 of about 985 commits. 62 merged PRs are from external authors, mostly one-commit. 892-member Discord.
8. Adoption: `@openuidev/react-lang` had 163,549 downloads in the week ending 2026-10-04 and 611,747 in the prior month; `vue-lang` 584/week, `angular-lang` 206/week. Eight companies self-listed in ADOPTERS.md; two published firsthand write-ups (Oodle, Standard Metrics). LangChain, assistant-ui, Lynx (ByteDance) and Mastra host integration docs or packages.
9. Reception: thin. One HN front-page thread (34 points) with complaints about the name (W3C Open UI CG), "open" branding, and "cross-platform" overclaim. No public comment from Vercel, Google, Anthropic, or OpenAI people found. No independent benchmark reproduction found.
10. Privacy: `@openuidev/lang-core` sends install telemetry in `postinstall` (opt-out); runtime telemetry was opt-out from 2026-08-05 to 2026-08-17 and is now opt-in.

## 1. Licensing and governance

- Repo license: MIT. The file header reads "Copyright (c) 2011-2024 Thesys Inc." ([LICENSE](https://github.com/thesysdev/openui/blob/main/LICENSE)). GitHub reports `license: MIT`, created `2024-12-02` ([API](https://api.github.com/repos/thesysdev/openui)).
- Packages: 16 of 17 `packages/*/package.json` declare `"license": "MIT"`. `@openuidev/react-email` (0.3.0) has no `license` field ([packages/react-email/package.json](https://github.com/thesysdev/openui/blob/main/packages/react-email/package.json)).
- Docs: the docs site lives in the same repo under `docs/` and inherits MIT. No separate docs license.
- Spec: two docs pages, [specification-v01](https://www.openui.com/docs/openui-lang/specification-v01) and [specification-v05](https://www.openui.com/docs/openui-lang/specification-v05) ("v0.5 (Latest)"), plus an [evolution guide](https://www.openui.com/docs/openui-lang/evolution-guide). They are prose and tables, not a grammar file. No `.ebnf`/`.peg` file exists in the repo (searched the clone). The parser is the de facto spec.
- CLA: none. [CONTRIBUTING.md](https://github.com/thesysdev/openui/blob/main/CONTRIBUTING.md) requires a maintainer-approved issue before any PR ("Pull requests without an approved issue may be closed"). [CODE_OF_CONDUCT.md](https://github.com/thesysdev/openui/blob/main/CODE_OF_CONDUCT.md) and [SECURITY.md](https://github.com/thesysdev/openui/blob/main/SECURITY.md) exist. No `GOVERNANCE.md`, no trademark policy, no steering group. A grep for "trademark", "governance", "steering", "contributor license" across repo Markdown finds only one blog post that uses "governance" in the sense of component-level security review.
- Standards body: none. The site says Thesys "maintains the open-source OpenUI framework and operates OpenUI Cloud" and that Thesys is behind OpenUI "much like Vercel is the company behind Next.js" ([openui.com](https://www.openui.com/)). The Thesys-written [State of Generative UI 2026](https://www.openui.com/blog/state-of-generative-ui-report) (2026-06-10) names one formal process in the space, MCP-Apps via SEP-1865, and describes none for OpenUI.
- Vercel : Next.js comparison. Matching facts: single corporate owner, MIT, hosted service sold alongside. Non-matching facts: Next.js has no "open standard" claim; Next.js had a decade of releases and a 1.0 before the hosted-platform coupling; OpenUI is 0.x, seven months old under this name, with the CLI and examples defaulting to OpenUI Cloud ("Switch agent-framework examples to OpenUI Cloud (#1103)", 2026-09-01; "Highlight OpenUI Cloud benefits in CLI (#834)", 2026-07-23).
- GitHub Discussions are disabled; the [public roadmap repo](https://github.com/thesysdev/roadmap) (created 2025-10-06) is archived.

## 2. Thesys Inc.

- Company: founded by Rabi Shanker Guha (CEO, GitHub `rabisg`) and Parikshit Deshmukh (`pd-builds`); San Francisco, 355 Bryant St ([openui.com footer](https://www.openui.com/)). Founding year reported as 2023 or 2024 depending on source.
- Funding: $4M seed led by Together Fund with 8VC, announced 2024-11-07 ([YourStory](https://yourstory.com/2024/11/thesys-secures-4-m-funding-led-together-fund), [Entrepreneur India](https://india.entrepreneur.com/en-in/news-and-trends/thesys-raises-usd-4-mn-funding-to-revolutionise-ai-user/482526)). No later round found ([Caplight](https://www.caplight.com/company/thesys)). Headcount estimates: 8 (Nov 2025, employbl), 23 (Inc42), 33 with 88% in South Asia (Revelio, Mar 2026). Not verified.
- Products, in order:
  - Crayon (`@crayonai/react-ui`, `@crayonai/react-core`): MIT React component kit, first published 2025-02-06, last 2026-02-03; still ~20k weekly downloads ([npm](https://registry.npmjs.org/@crayonai%2Freact-ui)).
  - C1 "Generative UI API": OpenAI-compatible endpoint that returns a JSON component tree, with `@thesysai/genui-sdk` (first published 2025-04-03, last 2026-07-01, 72 versions, 10,237 downloads/week). Show HN 2025-05-12 ([43965164](https://news.ycombinator.com/item?id=43965164), 1 point).
  - OpenUI (March 2026): open replacement for the C1 format.
  - OUI-1 (2026-09-08): a 26B/4B-active fine-tune of Google DiffusionGemma that writes OpenUI Lang; weights on Hugging Face under Gemma terms ([blog](https://www.openui.com/blog/oui-1), [runtimewire](https://runtimewire.com/article/thesys-ships-oui-1-local-generative-ui-model)).
- `@thesysai/genui-sdk` license is proprietary: "use the Software solely for internal development purposes", no redistribution or modification, "must not be used to develop or distribute competing SDKs" ([LICENSE.md](https://unpkg.com/@thesysai/genui-sdk/LICENSE.md)). This is the SDK OpenUI replaces.
- C1 status: "C1 documentation now lives here, under /legacy ... OpenUI is the actively developed successor to C1. Start there ... C1 and its APIs keep working" ([docs.thesys.dev/legacy](https://docs.thesys.dev/legacy)). No sunset date.
- Open core split. Open (MIT): language, parser, prompt generation, renderers, component libraries, chat UI, CLI, observability SDK. Hosted only (`api.thesys.dev`, `THESYS_API_KEY`): [Gateway](https://www.openui.com/docs/gateway) (multi-provider routing, failover, "model-output correction"), [Autofix API](https://www.openui.com/docs/autofix) (repairs invalid OpenUI Lang), Reports/Artifacts API, hosted Observability, `@openuidev/observability-cloud` sink. The [production guide](https://www.openui.com/docs/production) presents Gateway and Autofix as optional.
- Pricing (OpenUI Cloud, [thesys.dev/pricing](https://thesys.dev/pricing)): Free $0, 3K API calls/month, "Data may be used for training on free models"; Build $49/mo, 25K calls, $0.002/call after; Grow $499/mo, 500K calls, $0.001/call after, SSO/SAML; Scale custom with VPC/self-host. LLM tokens billed separately at provider rates. Reports API: 100 pages free, then $0.01/page.

## 3. Maturity

- History: first commit 2024-12-18 "init" (Crayon). "Migrate to openui" commit 2026-03-03. First `@openuidev/*` npm publish 2026-03-09 (`cli`, `react-ui`, `react-headless`); `react-lang` 2026-03-10; `lang-core` 2026-03-25 ([npm registry](https://registry.npmjs.org/@openuidev%2Flang-core)). About 985 commits on `main`.
- Versions (2026-10-08): `lang-core`, `react-lang`, `vue-lang`, `svelte-lang`, `angular-lang`, `a2ui` 0.3.2; `react-ui`, `react-headless` 0.17.0; `cli` 0.5.1; `browser-bundle` 0.1.5; `devtools` 0.2.2; `assistant-ui` 0.1.2; `server` 0.1.1; `react-email` 0.3.0; `observability` 0.0.4; `observability-cloud` 0.0.3; `langchain` 0.0.3. Nothing is 1.0.
- Cadence: 41 GitHub releases; releases on 2026-09-15, 09-19, 09-21, 09-23, 09-24, 10-05, 10-08 ([releases](https://github.com/thesysdev/openui/releases)). Changesets-driven since react-lang 0.3.0 ("Adopt automated release management via changesets", [PR 1069](https://github.com/thesysdev/openui/pull/1069)). Per-package CHANGELOG.md files start at 0.3.0; earlier history is untracked.
- Breaking changes: none labelled "breaking" in changelogs. `react-ui` 0.17.0 (2026-10-05) replaced Recharts with D3, removed `theme`, renamed `radius` to `barRadius` and `animated` to `isAnimationActive`, dropped several props, changed `height` semantics ([CHANGELOG](https://github.com/thesysdev/openui/blob/main/packages/react-ui/CHANGELOG.md)). Language v0.1 to v0.5 added state, queries, mutations, builtins ([evolution guide](https://www.openui.com/docs/openui-lang/evolution-guide)). The parser was rewritten from Rust/WASM to TypeScript days before launch ([blog 2026-03-13](https://www.openui.com/blog/rust-wasm-parser)).
- Stability claims: the docs make none. `@openuidev/a2ui` is marked "currently experimental" ([api-reference/a2ui](https://www.openui.com/docs/api-reference/a2ui)). README notes "OpenUI has no official cryptocurrency, token, or coin."
- Contributors: 50 listed. Largest external: `Shinyaigeek` (Ubie Inc.) 11, `shogun444` 9, `akinshaywai` 6; 32 externals with one commit ([contributors API](https://api.github.com/repos/thesysdev/openui/contributors)). 62 merged PRs by non-staff, non-bot authors out of 838 merged.
- Issues and PRs: 59 open / 105 closed issues; 108 open / 1,023 closed PRs (838 merged) ([search API](https://api.github.com/search/issues?q=repo:thesysdev/openui+is:issue)). ## 5. Reception

- HN front page once: "OpenUI: Open Standard for Generative UI", 2026-07-03, 34 points, 13 comments ([48770133](https://news.ycombinator.com/item?id=48770133)). Substantive points: `Keithamus` (Open UI CG participant): "It's unfortunate that this name was used. There is a W3C community group called OpenUI ... around for close to a decade." `tadfisher`: "Don't advertise 'cross-platform' and list React, React Native and Vue as your platforms." `trentor`: distrust of "Open" branding. `padolsey`: "Rendered div soup with pictures of data isn't a web standard and shouldn't be professing to be built for a11y." Founder `rabisg` replied that the language is platform independent and invited forks. The 2026-03-11 Show HN got 8 points, 0 comments ([47336804](https://news.ycombinator.com/item?id=47336804)).
- Parser blog thread, 2026-03-20 ([47461094](https://news.ycombinator.com/item?id=47461094)): commenters found the "Rust to TypeScript got faster" title misleading; the post's own conclusion credits an O(N^2) to O(N) streaming fix. `joaohaas`: "I really think the guy just prompted claude". `rabisg`: "a lot of claude prompting was definitely involved ... We are a small team". `JimDabell`: UI latency "is going to be completely dictated by the speed of the LLM, not the speed of the serialisation." In the same thread `rabisg` wrote: "We were running a JSON based format, Thesys C1, in production for a year before we realized we cannot add features fast enough."
- "OpenUI Ported to Assembly" (2026-05-15, [PR 517](https://github.com/thesysdev/openui/pull/517)): a joke PR by a Thesys engineer parodying AI-slop PRs; HN 4 points.
- Token-saving claim. Source: Thesys benchmark, seven prompts, GPT-5.2 at temperature 0, tiktoken `gpt-5`, formats derived from the same OpenUI output, latency modelled at 60 tok/s ([benchmarks](https://www.openui.com/docs/openui-lang/benchmarks), [benchmarks/README.md](https://github.com/thesysdev/openui/blob/main/benchmarks/README.md)). Aggregate reduction is 52.8% vs json-render and 51.7% vs C1; "67%" is the single best scenario (contact form, 893 to 294 tokens); "3x faster" is the same scenario divided by 60 tok/s. Thesys's own blog calls the savings "the receipt, not the reason" ([blog 2026-04-10](https://www.openui.com/blog/stop-making-ai-write-json)). The only critical external write-up found, Mervin Praison (2026-05-15, [mer.vin](https://mer.vin/2026/05/openui-lang-mit-generative-ui-that-cuts-llm-output-tokens-versus-json/)), is a desk review: latency "assumes a flat 60 tokens per second", dashboards save "only" about 40%, and the partial-UI-on-invalid-stream question is left open. No independent reproduction found.
- Reliability benchmark (Thesys, 2026-08-17, [blog](https://www.openui.com/blog/generative-ui-benchmark)): 46 prompts, 6 models, OpenUI 96.5% structural validity vs A2UI 95.7%, json-render about 16 points lower. Self-published.
- Security. Model output is restricted to registered components ("no off-script"). The docs also ship an [open-ended HTML escape hatch](https://www.openui.com/docs/agent/guides/open-ended-html) where one component's prop is a full HTML/CSS/JS document. Open issues: "Implement stricter parsing to avoid skipping invalid lines" ([582](https://github.com/thesysdev/openui/issues/582)), "input-guard layer for LLM-authored component props" ([660](https://github.com/thesysdev/openui/issues/660)). Telemetry: `lang-core` added opt-out `postinstall` telemetry on 2026-08-05 ([PR 931](https://github.com/thesysdev/openui/pull/931)) and opt-out runtime telemetry the same day ([PR 930](https://github.com/thesysdev/openui/pull/930)); runtime telemetry became opt-in on 2026-08-17 "per request in Slack" ([PR 991](https://github.com/thesysdev/openui/pull/991)); install telemetry stays opt-out (`DO_NOT_TRACK=1` disables) ([lang-core README](https://github.com/thesysdev/openui/blob/main/packages/lang-core/README.md#telemetry)).
- Reddit: Arctic Shift search across 37 subreddits found two one-point posts on 2026-10-08 in r/ChatGPT and nothing else since 2026-01-01. X and YouTube: searches returned no primary posts. Product Hunt: 2026-03-11, #4 of the day, 329 upvotes ([hunted.space](https://hunted.space/dashboard/thesys/launches/openui-2)). No comments from Vercel, Google, Anthropic, or OpenAI staff found anywhere.

## 6. History and name

- The name collides with three prior projects: the W3C Open UI Community Group (open-ui.org, chartered 2020-03-27, HN 348 points in 2025 ([43308278](https://news.ycombinator.com/item?id=43308278))); `wandb/openui` (Apache-2.0, created 2024-03-17, about 22k stars, describe-a-UI-and-render-HTML tool ([github](https://github.com/wandb/openui))); SAP OpenUI5. An npm package `openui` (unrelated, 2017) also exists. Two HN commenters, one a CG participant, objected to the collision; no response from Thesys on the name found.
- Domain: `openui.com` was registered 2000-03-13 and its record was updated 2026-02-23/24 (whois). The prior owner and transfer are not verified; the Wayback API rate-limited my requests.
- Thesys timeline: Crayon (2025-02) and C1 with a JSON "UI DSL" (2025-04, in production "for a year") preceded OpenUI. The GitHub repo `thesysdev/crayon` now redirects to `thesysdev/openui`; "Migrate to openui" landed 2026-03-03; packages published 2026-03-09; launch 2026-03-11. OpenUI Lang replaced the C1 JSON tree; Crayon's React components were carried into `@openuidev/react-ui`.
- Not verified: the Crayon star count before the rename; whether `openui.com` was bought from a prior holder; employee counts; any Thesys funding after the seed.
