# A written rule doesn't hold. A check does.
## Rules versus checks
| What I wrote down | What happened | What replaced it |
|---|---|---|
| never put a `$name` command token in a new agent's instructions | 83 sessions did it anyway | the tool that starts agents refuses |
| keep the second agent's copy of the instructions in sync | the hand-kept copy rotted | generated copy, then one shared file |
| keep file paths in docs current | 85 stale references | every path a doc mentions is checked |
| use judgment on tests that fail at random | two files said two different things | one scripted rerun |
