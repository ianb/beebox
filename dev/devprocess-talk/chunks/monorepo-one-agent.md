# An agent is equally good in every area at once, so I merged the repositories
## Why one repository
Five repositories: a person specializes, so the server, the extension, and the phone app each had their own checkout and their own expertise.
One repository: the agent has no specialty, so a change that crosses all three is one piece of work. 46 of 154 pieces of work since late August touched more than one package; the phone app with the server is the most common pair.
