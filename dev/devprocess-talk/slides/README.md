# Draft slides: "Each fix moves the bottleneck"

One Markdown file per slide, in the shape the presentation framework reads: a `# Title` line, a `## Eyebrow` line, then bullet lines. Two additions the framework does not render yet: fenced code blocks for verbatim excerpts, and a trailing `Notes:` paragraph of speaker notes (everything after the `Notes:` line is for the speaker). Files sort in presentation order: `NN-slug.md` is a main slide; `NNa-slug.md`, `NNb-slug.md` are the supporting slides behind it, which go deeper or show a concrete case. Drop the supporting files to get the short talk.

Every number and excerpt is from git or a local store on 2026-10-09; the command behind each number is in [the sweep reports](../reports/). The old product name is written `<old-package>` where a path or commit needed it. Instruction files are called CLAUDE.md where the slide describes the period before 2026-10-09, when they were renamed to AGENTS.md. The [inventory](../inventory.md) and [narrative](../bottlenecks.md) are the source material.

The same material atomized for a live co-presenter, one observation per card with speech cues, is in [../chunks/](../chunks/README.md); the gallery is [preview.html](../chunks/preview.html) and the catalog [index.md](../chunks/index.md).
