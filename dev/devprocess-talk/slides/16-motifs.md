# Ten moves that recur
## Name once, point to often
- Cut, regrow, budget: every hand-cut file regrew; the one with a budget held
- Prose rule → measured failure → check: sigils, Codex guidance, stale paths, flakes
- Fail closed: unknown counts as live; nothing overrides the liveness check
- Run-only head, agent only on handoff: 7 of 15 schedules never start an agent
- One file per thing, in git: issues, plans, schedules, skills; the hooks that validate code validate the queue
- The human is the slowest stage, so mark the gap: manual-testing tags, exhibits with one ask, journeys as proxy walker
- Instrument before gate: the test ledger, the context ledger, the skill counter
- Arrange context, don't automate judgment: the retrospective, the smoke review, the tour check
- The evidence stays in the tree: every question about the process is answered by reading, not asking
- The tool's user is the agent: the harness improves when an agent doing other work hits its edge
