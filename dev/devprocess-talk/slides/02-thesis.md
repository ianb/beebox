# The pattern, in eight moves
## Each relief exposed the next constraint
- 0 Jan–Feb: the agent forgets, and cannot read its tools → CLAUDE.md, per-edit lint, doctests, knowledge audits
- 1 Mar 3: instruction bloat → halve the file, nested files, "write a rule when corrected"
- 2 May 26: one agent at a time → worktrees, one router, skills, finish
- 3 Jun: bigger tasks → plans, cross-model review
- 4 Jul: findings outrun one person → one file per issue, in git
- 5 Aug: attention across a dozen streams; the suite; a second engine → workstreams, dashboard, schedules, hourly suite, smoke, Codex
- 6 Sep: size, persuasion, noise → calibration, budgets, alert digest
- 7 Oct: the process measures itself → transcript counts, retrospectives, dev audits

Notes:
The supporting slides give the pace curve, the size curve, and the vocabulary the rest of the talk uses. August is one burst rather than a sequence; the talk treats it as three threads hit together.
