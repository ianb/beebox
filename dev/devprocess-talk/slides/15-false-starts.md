- A committed Codex guidance copy (rotted in a month) → a verbatim generator → one file both agents read (Oct 9)
- One-directional review (Codex reviewing Codex) → the other family, always
- A single ideas file (39 → 1,681 lines) → one file per issue
- Four silent launchd jobs → one scheduler with overdue detection
- A 624-line finish agent → 165 lines plus two scripts

- Six "craft" skills (debug, frontend, codehealth…) → retired into the docs that own those areas
- Two rules in the package file lasted one day; one lasted 190 days and was dropped unreplaced
- 13 reverts in 8,778 commits; the fastest was two minutes
