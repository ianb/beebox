The skills, profiled

Most of these aren't tools — they're behavioral disciplines. Each one exists to bend the agent away from a default instinct that would otherwise produce worse work. Roughly, the longer the skill, the more default behavior it's fighting: a wrapper that just teaches a CLI is short; a discipline that has to out-argue the agent's shortcuts runs long and ends in an excuse→reality table.
