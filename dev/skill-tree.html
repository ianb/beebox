🌳 The skill tree

The skills as a talent tree. They build on each other along the arc of a task — fork a session, plan it, have a rival model attack the plan, build, verify, ship. Level = times invoked. The dim, padlocked nodes are born but never unlocked — the craft branch you haven't leveled into yet. The glowing gold path is the ritual that actually carries the work: cb-plan → codex. The ⚙ line under each node is the skill's equipment — the real CLI tools it wields (e.g. launch-worktree-session drives a launcher script, claude --worktree, and bin/worktrees; browse is all bin/browse).
