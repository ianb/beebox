> When you place a `chat.guide.card` in the same directory as a chat thread file, it gets picked up automatically by the chat job processor. Here's how it works:
> 
> **Discovery:** When a chat job runs, the agent:
> 1. Reads the chat thread file (referenced via `<thread ref="...">` in the job card)
> 2. Looks for a `chat.guide.card` **in the same directory** as that thread file
> 3. If found, reads it and follows its guidelines
> 
> **What the guide controls:**
> - **Triage rules** — when to respond vs. just acknowledge with `<seen />`
> - **Actions** — what kind of response to give (tone, depth, format)
> - **Context notes** — conversational norms, topics to watch for
> - **Experiments** — things the agent is trying out in this chat
> 
> **Key difference from other guides:** Unlike news or intake guides (which use `job-types` to associate with jobs), chat guides are found purely by **filesystem location** — the filename `chat.guide.card` in the same directory as the thread file.
> 
> So if you have a thread at `box/pool/some-chat/thread.chat-thread.card`, placing a guide at `box/pool/some-chat/chat.guide.card` would apply to that specific conversation.
