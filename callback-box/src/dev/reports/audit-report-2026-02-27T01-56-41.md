> Let me check the docs for chat-thread and chat-job cards.
> Use the `callback-in` attribute on `<seen>`:
> 
> ```xml
> <seen callback-in="30m">Check if anyone answered Alice's question</seen>
> ```
> 
> The text content is a note to your future self — when you're re-invoked, you'll find it as the last element in the thread and can read it to remember what you planned to do.
> 
> The value is a duration string (e.g. `"30m"`, `"2h"`). If new messages arrive before the timer fires, you'll be invoked for those messages instead, and the callback is effectively superseded.
