Some working sets are neither a landmark's default cards nor a single
parent-and-children review. A task may need a selected group of cards drawn from
several landmarks, then need that group again later.

Define an addressable saved-card-set concept, including how it records
cross-landmark references, how missing or moved cards appear, whether ordering
and pane placement are part of the saved state, and whether opening a set
changes chat destination. This should build on stable card addressability rather
than inventing a second reference format; see
[addressable-uris-for-cards](2026-05-11-addressable-uris-for-cards.md).
