While cheerio was being removed from `bbx view test`'s output step, the
boxholder said: "I think that's an old self debug path that we've improved
on. Could maybe be removed."

`bbx view test <slug>` renders an agent-authored view in Node against the real
cards and prints the HTML (`beebox/src/cli/commands/view/command.ts`). Box
agents are still told to use it: `beebox/box-docs/views.md` ("Testing a
View") and `beebox/box-docs/bbx-commands.md` ("bbx view test"), generated by
`beebox/src/core/docs-gen/package-docs/bbx-commands.ts` and
`beebox/src/core/views/doc/core.ts`. `bbx view check` and `bbx view
typecheck` share the render path.

To decide: what replaced it for an agent checking a view it wrote, and
whether `view check` and `view typecheck` stay. Removing it changes box
guidance, so it needs a knowledge audit.
