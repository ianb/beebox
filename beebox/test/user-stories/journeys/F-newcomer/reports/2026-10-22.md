## Harness defects

- **H1 — the walker's headless Chrome denies notification permission without a prompt.** Row 35. Checked in `aa-f-1`: `default -> denied`. The main need of this journey ("fewer things slip my mind") cannot be tested while this holds. Not fixed since 2026-10-09. Fix: grant `notifications` for the box origin in the browse profile (CDP `Browser.grantPermissions`) in `prepare`, or tell the walker the permission is denied by the instrument. Filed: [journey-browser-denies-notification-permission](../../../../../../issues/closed/code-quality/2026-10-22-journey-browser-denies-notification-permission.md).
- **H2 — `bin/browse scrollintoview bbx-…` does not resolve a `bbx-` id.** It passes the bare id to upstream as a CSS selector, which fails "Element not found". `TARGET_COMMANDS` (`browse/src/controls.ts:425-427`) omits `scrollintoview`. The walker prompt tells walkers to use exactly this form. In this walk it made shot 12 a copy of shot 11 and left the Home tab unreachable (row 47). Fix: add `scrollintoview` (and `scrollinto`) to `TARGET_COMMANDS` so it gets `#id`; it does not need the click precondition check. Fixed in `5866397ff`.
- **H3 — the walker discarded action output.** From 12:44 on, most of the walker's clicks end `>/dev/null`, so the "covered" refusal at 12:50:23 never reached its notes; it wrote "my click did nothing visible". Fix: the walker prompt should say never to discard the output of `click`, `fill`, or `scrollintoview`. Fixed in `5866397ff`.
- **H4 — a tab scrolled out of its strip is refused as "covered", not "offscreen".** The covering element named is the strip itself. The prompt says only `offscreen` can be fixed by scrolling, so a walker gives up. Fix: when the covering element is a scroll container that holds the target, report it as offscreen inside that container and suggest `scrollintoview`. Filed: [browse-calls-a-tab-in-a-scrolled-strip-covered](../../../../../../issues/closed/bugs/2026-10-22-browse-calls-a-tab-in-a-scrolled-strip-covered.md).
- **H5 — the browse key is not a signed-in owner.** `/auth/me` still returns 401 (row 34). Open: `issues/bugs/2026-10-09-browse-key-is-not-a-signed-in-owner.md`. Re-encounter noted on [browse-key-is-not-a-signed-in-owner](../../../../../../issues/bugs/2026-10-09-browse-key-is-not-a-signed-in-owner.md).
