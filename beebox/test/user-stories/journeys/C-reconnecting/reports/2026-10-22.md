## Harness defects

- **H1 — `scroll --selector` can hit a hidden element, and `mouse wheel` ignores the pointer.** Row 18. `[role=tabpanel]` matches the first tab panel in the DOM, which is the hidden one; `scroll` prints `✓ Done`. `mouse wheel` dispatched at (0,0) after `mouse move 300 300`. Fix: make `scroll --selector` refuse a zero-size match (or use the first visible match), as clicks already refuse; make `wheel` use the last `mouse move` position. Filed: [browse-scroll-selector-accepts-a-hidden-match](../../../../../../issues/bugs/2026-10-22-browse-scroll-selector-accepts-a-hidden-match.md).
- **H2 — a screenshot name was reused and the evidence overwritten.** `10-marisol-draft.png` was written at about 12:44:50 (the focused-view send) and again at 12:45:46. The first image was the only picture of row 20. Fix: `bin/browse screenshot` refuses to overwrite a file in a run's `shots/`, or appends a suffix. Filed: [walker-prompt-gaps-from-the-2026-10-22-walks](../../../../../../issues/docs-and-chores/2026-10-22-walker-prompt-gaps-from-the-2026-10-22-walks.md).

Fix: give the walker a wait that reads turn state (for example the "Thinking…" band or the chat status), or document one in the walker prompt. Filed: [walker-prompt-gaps-from-the-2026-10-22-walks](../../../../../../issues/docs-and-chores/2026-10-22-walker-prompt-gaps-from-the-2026-10-22-walks.md).
