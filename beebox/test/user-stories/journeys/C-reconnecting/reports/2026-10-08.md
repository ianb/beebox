## Harness defects

- **Screenshot order by filename.** `collect.ts:66-67` sorts sidecars by name.
  A shot named out of order produced a false 406-second wait and a hidden
  negative gap. Sort by sidecar timestamp. Fixed: `700c5c24e`.
- **Journey box agents use the developer's Claude account and settings.** The
  walk's box agent had the developer's Gmail, Calendar, Drive, personal
  `CLAUDE.md`, email, and Stop hook. A walker that accepts the Gmail offer
  would send real mail data into a test transcript. Preparation should run
  journey boxes with an isolated Claude config or with claude.ai connectors
  disabled, whatever the product fix (the connectors issue above). Filed: [`issues/bugs/2026-10-08-box-chat-agent-inherits-host-claude-account-connectors.md`](../../../../../../issues/closed/bugs/2026-10-08-box-chat-agent-inherits-host-claude-account-connectors.md). Not fixed.
- **Silent no-op clicks on id-less controls.** `browse/src/act.ts:274-278`
  documents that refs without a `bbx-` id get geometry checks only. A covered
  todo checkbox reports `✓ Done`. Filed: [`issues/bugs/2026-10-08-browse-ref-click-checks-only-geometry.md`](../../../../../../issues/closed/bugs/2026-10-08-browse-ref-click-checks-only-geometry.md); todo checkboxes are one
  more reason for [card chrome ids][noid].
- **Stale after-action guidance.** `after-action.md` step 3 says the browse
  key is not the box owner. `prepare/core.ts:97-106` now writes
  `agentBrowsing: "owner"`; no owner refusal occurred in this walk. Fixed: `700c5c24e`.
- **Broken links in the previous report.** The 2026-09-21 report's issue links
  use five `../` segments and resolve to `beebox/issues/`, which does not
  exist. Six are needed.
