## Harness defects

1. **`bin/browse upload` with a relative path gives the page an unreadable,
   0-byte file.** The wrapper passes paths to `agent-browser` unchanged; the
   browser does not resolve them against the caller's directory. The page gets a
   `File` with the right name and type, size 0, and a `NotReadableError` on read.
   The image pipeline reports that as a format the browser cannot read, the file
   upload as a dropped connection, and Capture as a network error. This turned
   the walk's headline into "the app does not take phone photos", which is
