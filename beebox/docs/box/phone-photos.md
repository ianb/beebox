# Add iPhone photos through an Apple Photos album

This is an optional input path. The boxholder creates an album in Apple Photos
on the phone; iCloud syncs it to their Mac; Bee Box Desktop, the Mac menu-bar
app, sends new album items to the box. The Mac and phone need to use the same
iCloud Photos library. These arrive as scan imports, so existing page pairing
and any review questions still apply.

To set it up, the boxholder needs to:

1. Install Bee Box Desktop on the Mac and pair it with this box: **Settings →
   Companion Apps → Copy Link (Mac)**, then **Pair with a Box…** in the app.
2. In the app, open **Preferences → Watched Folders**, choose **Add Photos
   Album…**, and choose this box. Approve the macOS Photos permission prompt.

The app creates its own upload credential on the box. It is listed by name under
**Settings → Scan uploaders**, where the person who set it up or the box owner
can revoke it.

The agent can explain these steps but leaves all Mac setup to the boxholder: do
not install the app, approve macOS permission prompts, or ask for or handle a
credential.
